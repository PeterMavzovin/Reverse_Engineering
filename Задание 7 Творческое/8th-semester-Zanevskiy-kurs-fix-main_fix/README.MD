# Зависимости

## Windows
Для запуска программы необходимо установить `tkinter`, но на Windows команда `pip install tkinter` **не** работает. Пакет добавляется, но всё равно появляется ошибка `ModuleNotFound`. <br>
Чтобы работало из под Windows необходимо устанавить Python вместе с Tkinter с официального сайта.

## Linux (wsl)
```shell
sudo apt install python3-tk
sudo apt install python3
```

# Запуск программы

Чтобы запустить программу в **режиме графического интерфейса** необходимо выполнить команду
```shell
python main.py
```

Чтобы запустить программу в **режиме командной строки** необходимо выполнить команду
```shell
python analyzer.py <имя файла>
```
